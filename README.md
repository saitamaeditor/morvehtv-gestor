# MorvehTV Gestor

Panel para gestionar el contenido de IDrive e2 de MorvehTV: explorar carpetas, crear secciones y series, subir vídeos directamente a e2 (por trozos, sin límite de tamaño), renombrar, mover, borrar y descargar.

Web estática (HTML, CSS y JS sin compilar) publicada en GitHub Pages. Se conecta a la API del servidor de MorvehTV (`config.js`) y solo pueden entrar las cuentas de MorvehTV que sean administradoras. No contiene ninguna clave.
